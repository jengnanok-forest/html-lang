                                HTML5
                                <picture> 響應式與新一代格式
                            

                            
                        

                        

                            針對不同螢幕尺寸載入不同比例圖片（Art Direction），並能優先載入體積更小的 WebP/AVIF 格式，不支援時自動退避 (Fallback) 至 JPG。
                        


                        

                            
 特點：節省手機行動網路流量

                            
 優勢：桌機用橫圖、手機載入直圖

                        


                        
                        

                            
                            
<picture>
  <!-- 手機版使用 WebP 橫圖 -->
  <source media="(max-width: 640px)" srcset="mobile.webp" type="image/webp">
  <!-- 桌機版使用高解析度 AVIF -->
  <source media="(min-width: 641px)" srcset="desktop.avif" type="image/avif">
  <!-- 不支援 picture 標籤時的預設退避 -->
  <img src="default.jpg" alt="響應式圖片範例" loading="lazy" class="w-full h-auto">
</picture>

                        

                    

                


                
                

                    

                        

                            

                                CSS
                                background-image 背景圖與黑罩層
                            

                            
                        

                        

                            適用於 Hero Banner 或區塊背景。透過 background-size: cover 滿版縮放，並疊加半透明黑罩層以提升白字可讀性。
                        


                        
                        

                            Hero Banner 標題文字範例
                        


                        
                        

                            
                            
/* CSS 語法 */
.hero-banner {
  background-image: 
    linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5)),
    url('hero.jpg');
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
  width: 100%;
  min-height: 350px;
}

                        

                    

                


                
                

                    

                        

                            

                                CSS
                                object-fit 圖片防變形裁切
                            

                            
                        

                        

                            解決固定容器尺寸（如 200x200 頭像或卡片圖）導致圖片拉伸變形的問題。
                        


                        
                        

                            

                                
                            

                            

                                
即時切換測試：

                                

                                    
                                    
                                    
                                

                            

                        


                        
                        

                            
                            
/* 保持比例填滿並自動裁切多餘邊界 */
.avatar-or-card-img {
  width: 200px;
  height: 200px;
  object-fit: cover;    /* cover | contain | fill | scale-down */
  object-position: center; /* 焦點位置 */
}

                                Hover 放大與遮罩動畫效果
                            

                            
                        

                        

                            提升相簿與產品卡片互動感，滑鼠懸停時進行平滑放大或浮現資訊文字。
                        


                        
                        

                            

                                
                                放大效果

                                遮罩效果
                            

                        


                        
                        

                            
                            
/* 1. 外層容器必須設定 overflow: hidden */
.img-container {
  overflow: hidden;
  border-radius: 8px;
}
/* 2. 圖片加上 transition 與 transform */
.img-container img {
  transition: transform 0.4s ease;

.img-container:hover img {
  transform: scale(1.1); /* Hover 時放大 1.1 倍 */
}

                        

                    

                


                
                

                    

                        

                            

                                Performance
                                Lazy Loading 與防版面位移 (CLS)
                            

                            
                        

                        

                            Google 網頁體驗指標的核心！設定 loading="lazy" 可讓未捲動到的圖片延後載入，同時指定 width/height 或 CSS aspect-ratio 避免圖片載入時推擠畫面的 CLS 問題。
                        


                        

                            
 注意事項：頁面最上方首圖 (LCP 圖片) 不要加 lazy loading，應設 fetchpriority="high"。

                        


                        
                        

                            
                            
<!-- 現代化標準高效能圖片標籤範例 -->
<img src="photo.jpg" 
     alt="說明文字" 
     width="800" 
     height="450" 
     loading="lazy" 
     decoding="async"
     style="aspect-ratio: 16/9; width: 100%; height: auto;">

                        

                    

                


                
                

                    

                        

                            

                                CSS Grid
                                響應式相簿與作品集網格
                            

                            
                        

                        

                            無需寫繁瑣的 Media Query 媒體查詢！使用 repeat(auto-fill, minmax(180px, 1fr)) 自動依螢幕寬度排列照片。
                        


                        
                        

                            
                            
                            
                        


                        
                        

                            
                            
/* 相簿外層容器 */
.photo-gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 16px;
}

/* 相簿內圖片固定比例與裁切 */
.photo-gallery img {
  width: 100%;
  aspect-ratio: 4 / 3;
  object-fit: cover;
  border-radius: 8px;
}

                                Text & Link
                                文字大小、顏色與文字連結語法
                            

                            
                        

                        

                            透過 CSS 屬性調整文字大小 (font-size)、顏色 (color) 與底線等樣式，並設定新頁籤開啟超連結。
                        


                        
                        

                            
這是 18px 紅色標題字體

                            
這是 13px 藍色說明內文

                            點此前往外部連結 (開啟新分頁) ➔
                        


                        
                        

                            
                            
<!-- 1. 調整文字大小與顏色 -->
<p style="font-size: 18px; color: #ef4444; font-weight: bold;">紅色大標題</p>
<p style="font-size: 14px; color: #2563eb;">藍色內文段落</p>

<!-- 2. 文字超連結 (target="_blank" 為開啟新分頁) -->
<a href="https://example.com" target="_blank" rel="noopener noreferrer" style="color: #059669; text-decoration: underline; font-weight: bold;">
  點此造訪官方網站
</a>

                        

                    

                


                
                

                    

                        

                            

                                HTML5 Video
                                HTML5 原生影片播放器語法
                            

                            
                        

                        

                            適用於伺服器上的 MP4/WebM 影片檔。包含播放控制面板 (controls)、預覽封面圖 (poster) 與自動靜音播放。
                        


                        
                        

                            
                            
<!-- HTML5 原生影片標籤 -->
<video controls poster="video-cover.jpg" width="100%" style="max-width: 800px; border-radius: 8px;">
  <source src="my-video.mp4" type="video/mp4">
  <source src="my-video.webm" type="video/webm">
  您的瀏覽器不支援 HTML5 影片播放。
</video>

<!-- 自動靜音循環播放 (常用於背景影片) -->
<video autoplay loop muted playsinline width="100%">
  <source src="bg-video.mp4" type="video/mp4">
</video>

                        

                    

                


                
                

                    

                        

                            

                                YouTube & Link
                                YouTube / 串流平台影片嵌入與按鈕連結語法
                            

                            
                        

                        

                            收錄兩種最常見情境：以 16:9 比例無縫嵌入網頁，或是建立漂亮的影片點擊跳轉按鈕。
                        


                        
                        

                            
                                 點此前往 YouTube 觀看影片
                            
                            ← 影片連結按鈕範例
                        


                        
                        

                            
                            
<!-- 1. 16:9 響應式 YouTube 影片嵌入 (使用 CSS aspect-ratio) -->
<iframe 
  src="https://www.youtube.com/embed/VIDEO_ID" 
  title="YouTube 影片播放器" 
  frameborder="0" 
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" 
  allowfullscreen
  style="width: 100%; aspect-ratio: 16 / 9; border-radius: 8px;">
</iframe>

<!-- 2. 影片超連結按鈕 (點擊另開新分頁跳轉至影片頁) -->
<a href="https://www.youtube.com/watch?v=VIDEO_ID" 
   target="_blank" 
   rel="noopener noreferrer" 
   style="display: inline-block; padding: 10px 20px; background-color: #ff0000; color: #ffffff; border-radius: 6px; text-decoration: none; font-weight: bold; font-size: 14px;">
  ▶ 點此前往觀看完整影片
</a>
